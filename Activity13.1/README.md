## Objective

Create an `AccountRulesEngine` using in-memory `Map` lookup tables to determine:

- Savings minimum balance
- Savings interest rate
- Current account overdraft limit
- Fixed deposit interest rate

| 2 years | Rs 7500.0 | 3.00% |
